# 🍽️ Zomato Restaurant Data Analysis — Cognifyz Technologies Internship

An end-to-end exploratory data analysis of a 9,551-row Zomato restaurant dataset, completed as part of the **Cognifyz Technologies Data Analysis Internship**, uncovering patterns in cuisine popularity, restaurant distribution, and the relationship between customer engagement and ratings.

## 📌 Overview

This project analyzes a real-world restaurant dataset from Zomato to extract actionable business insights around cuisine trends, geographic restaurant distribution, and what drives customer ratings. The analysis was delivered across **three progressive levels** as part of the internship's structured task format, each building on the previous with deeper statistical and visual analysis.

## 🎯 Objectives

- Clean and prepare a real-world, messy restaurant dataset for analysis
- Identify the most common cuisines and their distribution across restaurants
- Determine which cities/regions have the highest restaurant density
- Analyze the relationship between customer votes and restaurant ratings
- Visualize findings with clear, business-friendly charts

## 🔑 Key Findings

- **North Indian cuisine** is the most common cuisine type, representing **41.5%** of restaurants in the dataset
- **New Delhi** leads all cities in total restaurant count by a significant margin
- There is a **weak positive correlation** between the number of votes a restaurant receives and its average rating — popularity doesn't strongly guarantee a higher rating
- The dataset lacked raw customer review text, so **rating text categories** (e.g. "Excellent", "Good", "Average") were used as a proxy for sentiment-style analysis instead of fabricating review content

## 🚀 Getting Started

### Prerequisites
- Python 3.9 or higher

### Installation

```bash
# Clone the repository
git clone https://github.com/LokavarapuGovindu1/zomato-data-analysis-cognifyz.git
cd zomato-data-analysis-cognifyz

# (Optional but recommended) Create a virtual environment
python -m venv venv
source venv/bin/activate   # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### Usage

**Option 1 — Run the full analysis as a script:**
```bash
python main.py --data data/zomato.csv
```
This runs all three levels of analysis end-to-end and saves all generated charts to the `outputs/` folder.

**Option 2 — Explore step-by-step in Jupyter:**
```bash
jupyter notebook
```
Open any of the notebooks in the `notebooks/` folder to explore the analysis interactively, from data cleaning through to visualization.

## 📊 Analysis Breakdown

**Level 1 — Data Exploration & Cleaning**
- Handling missing values and data type corrections
- Descriptive statistics and initial distribution checks

**Level 2 — Cuisine & Geographic Analysis**
- Most common cuisines and their market share
- Restaurant distribution by city
- Price range and cost-for-two trends

**Level 3 — Ratings & Correlation Analysis**
- Relationship between votes and ratings
- Rating text category breakdown (used in place of missing raw review text)
- Final business recommendations based on findings

## 🧗 Challenges & Learnings

- The dataset did not include raw customer review text, only rating categories — rather than fabricating sentiment data, rating text buckets were used as an honest proxy for analysis.
- Cleaning inconsistent city/cuisine naming conventions required careful string normalization before aggregating counts.
- Interpreting a weak correlation correctly (rather than overstating it) was an important part of presenting honest, defensible insights.
